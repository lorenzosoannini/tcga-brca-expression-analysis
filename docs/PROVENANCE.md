# Provenance

Original project: **Gene Expression Data Analysis in BRCA**, Lorenzo Soannini,
Bioinformatics university exam, 2024. The original presentation is the reference
for the exam results. It is copied byte-for-byte, including its original wording
and embedded bibliography. Interpretive qualifications are in METHODOLOGY.md.

| Repository artifact | Local exam source |
| --- | --- |
| `docs/Bioinformatics - BRCA.pdf` | Presentation with the same name |
| `results/exam/BRCA/` | Original `results/BRCA/` analysis tables and PDF figures |
| `results/exam/PCA/` | Original `PCA/results/BRCA/` directory |
| `archive/code/GEAnalysis.R` | Original `GEAnalysis.R` |
| `archive/code/PCA/myPCA.R` | Original `PCA/myPCA.R` |
| `archive/code/enrichR/` | Original enrichment script and plotting helper |
| `docs/assets/` | PNG previews rendered from historical PDF figures |
| `scripts/` | Portable revisions and artifact checks added for the portfolio |

SHA-256 checksums in `artifact-checksums.json` identify the copied historical
artifacts. Archive scripts retain their machine-specific paths for traceability;
use `scripts/` for execution. No new BRCA experiment is presented as an exam
result. The available scripts follow course methods; this repository does not
claim a novel statistical method or sole authorship of all teaching scaffolding.

Excluded: the large expression input, clinical table, intermediate patient CSV,
survival tutorials on unrelated data, source-reference screenshots/bookmarks, and auxiliary BioMart query templates whose
expected inputs are not fully preserved. Existing BioMart output tables remain
among the historical artifacts, without implying their queries were rerun.

The slides contain third-party figures and literature references with their
original attributions. TCGA data, database annotations and referenced material
retain their respective provenance. No blanket license is asserted over those
materials or the original course scaffolding.
